📖 Lý Thuyết Ngắn Gọn 10 Chương PRO192 (Java OOP)

1. Java Basics, Primitive Types & Pass-by-Value

  • 8 kiểu nguyên thủy: byte(1B), short(2B), int(4B), long(8B), float(4B), double(8B), char(2B), boolean.
  • BẪY Java LUÔN truyền tham trị (Pass-by-Value) — với Object, nó copy giá trị địa chỉ tham chiếu (đổi thuộc tính bên trong thì ảnh hưởng, gán lại obj = new ... thì KHÔNG ảnh hưởng bên ngoài!).
  • Phép toán trên byte/short/char tự động nâng lên int (VD: byte c = a + b; ⇒ Compile Error nếu không ép kiểu!).

2. OOP Core, Static, Final & Thứ Tự Khởi Tạo

  • Thứ tự chạy khi new Child(): static block Cha → static block Con → instance block & Constructor Cha → instance block & Constructor Con.
  • final: Biến (hằng số, không gán lại), Method (không override), Class (không kế thừa — VD: String).
  • static method KHÔNG dùng được this hay super, không gọi trực tiếp biến instance.

3. Inheritance, Polymorphism & Casting

  • Variable Hiding vs Method Overriding: Biến và static method tra theo kiểu khai báo (Reference Type) lúc compile; instance method tra theo đối tượng thực tế (Object Type) lúc runtime!
  • Upcasting (Con → Cha): luôn an toàn, tự động. Downcasting (Cha → Con): phải ép kiểu tường minh, sai kiểu thật ⇒ ClassCastException lúc runtime (luôn kiểm tra bằng instanceof).

4. String Pool, StringBuilder & Wrapper Cache

  • String là Immutable (bất biến). "abc" == "abc" là true (cùng String Pool), nhưng new String("abc") == "abc" là false (khác vùng nhớ Heap). Luôn so sánh nội dung bằng .equals()!
  • StringBuilder (nhanh, không thread-safe) vs StringBuffer (chậm hơn, synchronized thread-safe).
  • BẪY INTEGER CACHE Integer a = 127, b = 127; a == b là true (cache từ -128 đến 127), nhưng 128 == 128 với 2 biến Integer là false!

5. Abstract Classes & Interfaces

  • Lớp con kế thừa Abstract Class hoặc implements Interface bắt buộc phải cài đặt hết các abstract method (trừ khi chính lớp con cũng là abstract).
  • Một interface có thể extends nhiều interface khác; class dùng extends cho class và implements cho interface.

6. Exception Handling (Checked vs Unchecked)

  • Checked Exception (IOException, SQLException, ClassNotFoundException): bắt buộc try-catch hoặc throws lúc compile.
  • Unchecked Exception (kế thừa RuntimeException: NullPointerException, ArithmeticException, ArrayIndexOutOfBoundsException, ClassCastException): không bắt buộc khai báo.
  • Khối finally LUÔN chạy (kể cả khi try/catch có return!), trừ duy nhất trường hợp gọi System.exit(0) hoặc crash JVM.
  • Nhiều khối catch: phải đặt lớp Exception Con trước, Cha sau (ngược lại ⇒ Compile Error!).

7. Collections & Iterator

  • Xóa phần tử khi đang duyệt for-each sẽ ném ConcurrentModificationException ⇒ phải dùng Iterator.remove() hoặc vòng lặp for ngược từ size-1 về 0!
  • Hợp đồng equals & hashCode: Nếu a.equals(b) == true thì BẮT BUỘC a.hashCode() == b.hashCode() (chiều ngược lại không bắt buộc).

8. Sorting (Comparable vs Comparator) & Generics

  • Comparable (java.lang): cài compareTo(T o) ngay trong class (1 tiêu chí sắp xếp tự nhiên).
  • Comparator (java.util): cài compare(T o1, T o2) bên ngoài (tùy biến nhiều tiêu chí sắp xếp).
  • Generics Type Erasure: Thông tin kiểu <T> bị xóa lúc compile; không thể viết new T() hay List<int> (phải dùng Wrapper List<Integer>).

9. Java I/O Streams & Serialization

  • Byte Streams: InputStream / OutputStream (đọc file nhị phân, ảnh, audio). Character Streams: Reader / Writer (đọc file text Unicode).
  • Serializable là Marker Interface (không có method nào). Từ khóa transient và static đánh dấu thuộc tính KHÔNG bị ghi xuống file khi serialize (khi đọc lại sẽ mang giá trị mặc định null / 0).

10. Mẹo Code Tracing FE (Ăn Điểm Tuyệt Đối)

  • Kiểm tra Compile Error trước tiên (kiểu trả về, ép kiểu byte/short, private/final override, catch sai thứ tự, biến local chưa khởi tạo).
  • Cẩn thận i++ (dùng rồi mới tăng) vs ++i (tăng rồi mới dùng), và phép short-circuit && / || (vế phải không chạy nếu vế trái đã quyết định kết quả!).
